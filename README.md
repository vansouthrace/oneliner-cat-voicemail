An entry for the [make.fun bounty "Funniest Cat Voicemail Greeting"](https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443): the funniest one-line voicemail greeting a cat would record, max 120 characters.

## The entry

> Meow. You've reached Tuna. I am currently inside the box you bought me a bed for. Leave a message.

## How to run

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the single entry line to `/output/entry.txt` and validates the 120-character gate before writing. Requires Node 22.18 or later (it runs TypeScript as-is).
